# MEDEUS

**MEDEUS** is a one-page conversational website, with ChatGPT-like multi-turn interaction expressed through an original living cosmic interface. The long-term intelligence layer is ASTRADELIA behind a governed backend gateway (NOT YET CONNECTED), not a conventional chatbot UI or a native app. The user-approved **visual master is immutable**. MEDEUS is a separate product/interface, not an ASTRADELIA core node.
